# EKIgrav_faultINV
MATLAB implementation of Regularized Ensemble Kalman Inversion (EKI) for estimating 2D fault geometry from gravity data, with uncertainty quantification

Cite:
Laby, D. A., Biswas, A., Heriyanto, M. F., Sungkono, S., Bery, A. A., Ahmed, B. M., Nur Rochman, J. P. G., Purwanto, M. S., & Utama, W. (2026). Interpreting the Gravity Signatures of Faults: Efficient 2D Fault Geometry Estimation Using Regularized Ensemble Kalman Inversion with Sensitivity and Uncertainty Assessment. Submitted.
